# Production Phase 20 Continuous Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add lightweight GitHub Actions validation for Ruff, deterministic pytest unit/integration behavior, and an 85 percent whole-package branch-coverage gate.

**Architecture:** One Ubuntu/Python 3.11 job installs the existing native adapters plus pinned CI tools, runs Ruff, executes hardware-free unit and integration tests in separate coverage-appending steps, enforces combined coverage, and uploads `coverage.xml`. Existing camera/model interactions remain mocked or synthetic; the workflow never launches the application or invokes YOLO.

**Tech Stack:** GitHub Actions, Python 3.11, Ruff 0.16.4, pytest 9.1.1, pytest-cov 7.1.0, coverage.py, existing unittest-compatible tests.

**Spec:** `docs/superpowers/specs/2026-08-23-phase-20-ci-design.md`

## Global Constraints

- Do not modify working webcam, YOLO, ByteTrack, checkout, cart, API, or persistence algorithms.
- CI must not open a camera/window, run inference, download weights, require Apple MPS/GPU, use secrets, or contact application cloud services.
- Use Python 3.11 and one Ubuntu job.
- Use only Ruff for linting and formatting.
- Measure all `smart_retail` modules with branch coverage and enforce 85 percent.
- Do not add a README badge because no GitHub remote owner/repository is known.
- Do not create Docker Compose, deployment, publishing, Codecov, or Sonar configuration.
- The repository has no valid Git `HEAD`; preserve working-tree changes without inventing commit history.

```python
"""Static policy checks for the deterministic GitHub Actions pipeline."""

import tomllib
import unittest
from pathlib import Path


PROJECT_ROOT = Path(__file__).resolve().parents[1]
WORKFLOW_PATH = PROJECT_ROOT / ".github/workflows/ci.yml"


class ContinuousIntegrationConfigurationTests(unittest.TestCase):
    def test_ci_tooling_is_pinned_and_configured(self) -> None:
        metadata = tomllib.loads(
            (PROJECT_ROOT / "pyproject.toml").read_text(encoding="utf-8")
        )
        ci_dependencies = "\n".join(
            metadata["project"]["optional-dependencies"]["ci"]
        ).lower()

        self.assertIn("pytest==9.1.1", ci_dependencies)
        self.assertIn("pytest-cov==7.1.0", ci_dependencies)
        self.assertIn("ruff==0.16.4", ci_dependencies)
        self.assertEqual(metadata["tool"]["ruff"]["target-version"], "py311")
        self.assertEqual(metadata["tool"]["coverage"]["report"]["fail_under"], 85)

    def test_workflow_enforces_quality_tests_and_coverage_without_hardware(self) -> None:
        workflow = WORKFLOW_PATH.read_text(encoding="utf-8")

        for required in (
            "actions/checkout@v6",
            "actions/setup-python@v6",
            "actions/upload-artifact@v7",
            "python-version: '3.11'",
            "python -m ruff check",
            "python -m ruff format --check",
            "python -m pytest",
            "--cov-append",
            "--fail-under=85",
            "coverage.xml",
        ):
            self.assertIn(required, workflow)

        for forbidden in (
            "python app.py",
            "yolov8n.pt",
            "${{ secrets.",
            "docker build",
        ):
            self.assertNotIn(forbidden, workflow)

    def test_unknown_repository_does_not_publish_a_speculative_badge(self) -> None:
        readme = (PROJECT_ROOT / "README.md").read_text(encoding="utf-8")
        self.assertNotIn("actions/workflows/ci.yml/badge.svg", readme)


if __name__ == "__main__":
    unittest.main()
```

- [ ] **Step 1: Create the workflow**

Create `.github/workflows/ci.yml`:

```yaml
name: CI

on:
  push:
    branches: [main, develop]
  pull_request:
  workflow_dispatch:

permissions:
  contents: read

concurrency:
  group: ci-${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  quality-and-tests:
    runs-on: ubuntu-latest
    timeout-minutes: 20
    env:
      MPLBACKEND: Agg
      OPENCV_LOG_LEVEL: ERROR
      PYTHONUNBUFFERED: "1"
      SMART_RETAIL_MODEL_PATH: /tmp/ci-model-must-not-load.pt
      YOLO_CONFIG_DIR: ${{ runner.temp }}/ultralytics

    steps:
      - name: Check out repository
        uses: actions/checkout@v6

      - name: Set up Python 3.11
        uses: actions/setup-python@v6
        with:
          python-version: '3.11'
          cache: pip
          cache-dependency-path: |
            pyproject.toml
            requirements.txt

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          python -m pip install --editable ".[vision,test,ci]"

      - name: Lint
        run: python -m ruff check app.py src tests training

      - name: Check formatting
        run: python -m ruff format --check app.py src tests training

      - name: Run unit and deterministic adapter tests
        run: |
          python -m pytest tests -q \
            --ignore=tests/test_api.py \
            --ignore=tests/test_api_service.py \
            --ignore=tests/test_persistence.py \
            --cov=smart_retail \
            --cov-branch \
            --cov-report=

      - name: Run API and database integration tests
        run: |
          python -m pytest \
            tests/test_api.py \
            tests/test_api_service.py \
            tests/test_persistence.py \
            -q \
            --cov=smart_retail \
            --cov-branch \
            --cov-append \
            --cov-report=

      - name: Generate coverage report
        run: python -m coverage xml -o coverage.xml

      - name: Enforce coverage threshold
        run: python -m coverage report --show-missing --fail-under=85

      - name: Upload coverage XML
        if: ${{ always() }}
        uses: actions/upload-artifact@v7
        with:
          name: coverage-report
          path: coverage.xml
          if-no-files-found: ignore
          retention-days: 14
```
