# Portfolio screenshots

This directory is reserved for screenshots captured from the real application.
No generated or fabricated dashboard images are used.

Recommended filenames:

- `dashboard.png`
- `recent-events.png`
- `sessions.png`
- `session-detail.png`
- `system-metrics.png`
- `opencv-vision.png`

Capture dashboard pages at approximately 1440 × 900 with browser chrome
cropped consistently. Preserve the **DEMO MODE** badge whenever synthetic
commands produced the displayed state. Capture `opencv-vision.png` only from a
real webcam/YOLO/ByteTrack run. Review every image for personal information,
terminal paths, notifications, and secrets before committing it.

After adding verified images, embed a concise hero screenshot or GIF under the
root README's Demo section. Do not commit raw recordings or large unoptimized
assets; link to a hosted demonstration when appropriate.
